## 1. 系统简介

### 1.1 系统定位

PharmaAgent System 是一个面向医药行业的**客户关系管理与智能决策支持系统**，基于美国CMS Open Payments公开数据，为医药销售团队提供：

- 📊 **医生画像分析**：基于RFM模型的医生价值评估
- 🎯 **客户分群**：K-Means聚类自动识别高价值客户
- 🤖 **AI策略生成**：Dify智能体自动生成个性化市场策略
- 📈 **数据可视化**：3D散点图、雷达图、仪表板

### 1.2 用户角色

| 角色 | 权限 | 典型使用场景 |
|------|------|------------|
| **Viewer（查看者）** | 查看医生列表、报告 | 销售代表查看客户信息 |
| **Analyst（分析师）** | 执行聚类分析、生成AI报告 | 市场分析师制定策略 |
| **Admin（管理员）** | 全部权限 + 用户管理 | 系统管理员、部门主管 |

### 1.3 核心数据指标

**RFM模型**（客户价值评估标准）：
- **R (Recency)**：最近互动时间（天数越小=越活跃）
- **F (Frequency)**：互动频次（次数越多=关系越稳定）
- **M (Monetary)**：累计金额（金额越高=价值越大）

## 3. 核心功能详解

### 3.1 医生管理

#### 功能1：查看医生列表

**路径**：左侧菜单 → 「医生管理」

**功能**：
- 分页浏览所有医生（默认每页20条）
- 查看医生基本信息：姓名、NPI、专业、州
- 查看RFM指标：Recency、Frequency、Monetary
- 查看分群标签（Cluster ID）

**操作步骤**：
1. 点击「医生管理」菜单
2. 使用顶部筛选器：
   - **专业筛选**：下拉选择（如：心血管内科）
   - **州筛选**：多选（如：CA、NY）
   - **分群筛选**：选择聚类编号（0、1、2...）
   - **搜索框**：输入医生姓名或NPI
3. 点击「查询」按钮

#### 功能2：查看医生详情

**操作步骤**：
1. 在医生列表中点击医生姓名
2. 进入详情页，查看：
   - 基本信息（姓名、NPI、专业、地址）
   - RFM指标卡片
   - 最近支付记录（最多10条）
   - 历史趋势图表

#### 功能3：批量导入医生

**路径**：医生管理 → 「批量导入」按钮

**操作步骤**：
1. 下载模板：点击「下载模板」获取 Excel 模板
2. 填写数据：
   - 必填字段：`npi`、`first_name`、`last_name`
   - 可选字段：`specialty`、`state`、`primary_type`
3. 上传文件：点击「上传」，选择填好的Excel文件
4. 系统自动校验：
   - 检查NPI格式（10位数字）
   - 检查重复记录
5. 导入完成，显示统计：插入X条，跳过Y条

### 3.2 聚类分析

#### 功能概述

使用 **K-Means算法** 将医生分为K个群体，每个群体具有相似的RFM特征。

**业务价值**：
- 识别高价值核心客户（High-Value Cluster）
- 发现潜力客户（Potential Cluster）
- 区分低频客户（Low-Engagement Cluster）

#### 操作步骤

**路径**：左侧菜单 → 「聚类分析」

1. **配置参数**（左侧面板）：
   - **聚类数K**：拖动滑块选择（推荐K=2或3）
   - **特征选择**：勾选使用的特征
     - ✅ Recency（最近互动天数）
     - ✅ Frequency（互动频次）
     - ✅ Monetary（累计金额）

2. **执行分析**：
   - 点击「开始分析」按钮
   - 等待进度条（约10-30秒）

3. **查看结果**：
   - **分群统计表**：
     - Cluster 0：31.6万人，平均金额$7,713
     - Cluster 1：42.2万人，平均金额$126
   - **3D散点图**：
     - X轴 = Recency
     - Y轴 = Frequency
     - Z轴 = Monetary
     - 颜色 = 聚类编号
   - **特征对比雷达图**：展示各群体的RFM特征差异

4. **导出报告**：
   - 点击「下载CSV」按钮
   - 导出包含所有分群统计的Excel文件

#### 最佳实践

**如何选择K值？**
- **K=2**：简单二分法（高价值 vs 普通客户）
- **K=3**：三层分级（核心客户 / 潜力客户 / 一般客户）
- **K≥4**：精细化分群（需结合业务经验）

**解读示例**：
- **Cluster 0（高价值群体）**：
  - 平均金额：$7,713
  - 平均频次：45次
  - 策略：高强度学术拜访，举办专家会议
- **Cluster 1（大众群体）**：
  - 平均金额：$126
  - 平均频次：3次
  - 策略：低成本数字化营销，邮件推送

### 3.3 AI策略生成

#### 功能概述

基于 **Dify智能体** 和 **大语言模型（LLM）**，自动为每个聚类生成：
- 群体特征分析
- 营销策略建议
- 资源投放建议
- 风险提示

#### 操作步骤

**路径**：聚类分析页面 → 选择聚类 → 「生成AI策略」

1. **选择目标群体**：
   - 在聚类结果列表中点击任意聚类（如：Cluster 0）

2. **输入提示词（可选）**：
   - 在弹窗中输入特殊要求（如："侧重合规性"）
   - 或直接点击「生成」使用默认模板

3. **观看流式输出**：
   - 系统实时显示AI生成内容（打字机效果）
   - 生成时间约15-30秒

4. **查看报告**：
   - 报告采用 **Markdown格式**，包含：
     ```markdown
     ## 1. 群体洞察
     该群体为高价值核心医生，平均处方金额$15,000...

     ## 2. 核心策略
     "学术引领，深度绑定"

     ## 3. 具体行动计划
     - **学术会议**：举办国家级学术峰会...
     - **拜访频率**：每月至少2次面对面拜访
     - **资源投放**：优先分配新药试用装...

     ## 4. 预期ROI分析
     投入产出比预计1:8...
     ```

5. **保存报告**：
   - 系统自动保存到数据库
   - 可在「AI报告」菜单查看历史记录

#### 注意事项

⚠️ **使用前提**：需配置Dify API密钥（见部署指南）
⚠️ **合规提示**：AI生成内容仅供参考，需结合企业合规政策
⚠️ **成本控制**：每次生成约消耗0.01-0.05美元API费用

### 3.5 系统日志（管理员功能）

#### 功能概述

记录系统关键操作，用于安全审计和问题排查。

#### 日志类型

**1. 登录日志（Login Logs）**
- 记录内容：用户名、IP地址、浏览器、登录时间、成功/失败
- 用途：检测异常登录、账户安全审计

**2. 操作日志（Operation Logs）**
- 记录内容：用户、模块、HTTP方法、路径、耗时、状态码
- 用途：追踪数据修改、性能分析

#### 操作步骤

**路径**：左侧菜单 → 「系统日志」

1. **切换Tab**：选择「登录日志」或「操作日志」

2. **筛选查询**：
   - 登录日志：按用户名、状态（成功/失败）
   - 操作日志：按模块（Doctor/Analysis/Report）、方法（POST/PUT/DELETE）

3. **导出日志**：
   - 点击「导出CSV」按钮
   - 下载Excel文件（最多10,000条）

## 4. 使用流程示例

### 场景1：新入职销售如何快速上手

**目标**：了解负责区域的医生分布

**步骤**：
1. 登录系统（使用公司分配的账户）
2. 进入「Dashboard」查看全局数据
3. 进入「医生管理」，筛选：
   - 州 = "CA"（加州）
   - 专业 = "Cardiology"（心血管科）
4. 按Monetary排序，查看Top 100医生
5. 点击医生姓名，查看详细RFM画像和历史记录
6. 将重点医生NPI记录到CRM系统

---

### 场景2：市场部制定季度拜访策略

**目标**：为不同医生群体制定差异化策略

**步骤**：
1. 进入「聚类分析」
2. 设置K=3，执行聚类
3. 查看结果：
   - Cluster 0：高价值医生（3万人）
   - Cluster 1：中等价值（20万人）
   - Cluster 2：低价值（50万人）
4. 对Cluster 0 生成AI策略：
   - 点击「生成AI策略」
   - 输入提示词："侧重学术会议和KOL绑定"
   - 查看报告，复制核心建议
5. 重复步骤4，为Cluster 1、2 生成策略
6. 下载CSV报告，导入到Excel制作PPT
7. 提交给销售总监审批

---

### 场景3：数据分析师优化分群模型

**目标**：找到最优的K值

**步骤**：
1. 进入「聚类分析」
2. 依次测试K=2、3、4、5：
   - 观察Silhouette Score（轮廓系数，越接近1越好）
   - 观察3D散点图的分离度
3. 记录每个K值的结果：
   - K=2：Score=0.65，分离明显
   - K=3：Score=0.58，中等分离
   - K=4：Score=0.42，过度分割
4. 结论：选择K=2，简单且效果最好
5. 生成最终报告，提交给业务团队

## 5. 常见问题FAQ

### Q1: 为什么我无法执行聚类分析？

**原因**：权限不足（Viewer角色无此权限）
**解决方案**：联系管理员升级为Analyst角色。

---

### Q2: AI策略生成失败，提示"API错误"？

**排查步骤**：
1. 检查网络连接
2. 确认Dify API密钥是否配置（联系管理员）
3. 查看后端日志：`backend/logs/app.log`

---

### Q3: 如何导出医生列表？

**方法1**：使用浏览器打印功能（Ctrl+P）
**方法2**：后端API支持CSV导出（需前端开发）
**临时方案**：复制表格内容到Excel

---

### Q4: 系统性能慢，如何优化？

**常见原因**：
- 数据库文件过大（pharma.db > 1GB）
- 同时查询大量数据（未分页）

**解决方案**：
- 清理历史日志（参见部署指南）
- 使用筛选器缩小查询范围
- 联系管理员优化数据库索引

---

### Q5: 忘记密码怎么办？

**方案1**（推荐）：联系管理员重置密码
**方案2**（仅管理员）：运行后端脚本：
```bash
cd backend/scripts
python reset_password.py --username your_username --password new_password
```

---

### Q6: 医生数据多久更新一次？

**数据来源**：CMS Open Payments（每季度更新）
**更新方式**：管理员手动运行ETL脚本导入最新数据
**建议频率**：每季度或每年更新一次
