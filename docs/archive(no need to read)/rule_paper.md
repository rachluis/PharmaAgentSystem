# 🚨 Core Rules (核心写作法则 - 必须严格遵守)

## 1. 风格规范 (Style Guidelines)

* **去 AI 味** : 严禁使用“总而言之”、“综上所述”、“我们都知道”、“迷人的”、“值得注意的是”等大模型常用连接词。
* **学术化表达** :
* ❌ “这个系统跑得很快”
* ✅ “系统经测试，在千万级数据量下的查询响应时间稳定在 200ms 以内”。
* ❌ “我觉得数据很重要”
* ✅ “数据质量直接决定了画像模型的准确性上限”。
* **客观陈述** : 多用被动语态或以“本文”、“本系统”为主语。避免第一人称“我”。
* **数据颗粒度** : 凡是涉及数据处理，必须精确到个位数（如：738,772 名医生），严禁使用“海量”、“大量”等模糊词汇代替具体数字。

## 2. 逻辑与事实规范 (Logic & Fact)

* **真实性** : 所有技术实现细节必须与 `DATA_DICTIONARY.md` 和代码逻辑一致（例如：如果是 SQLite，就不要写 MySQL）。
* **引用规范** : 仅引用真实存在的经典算法文献（如 Breiman 的随机森林，MacQueen 的 K-Means）或知网/Google Scholar 上可查证的医药营销/CRM 相关文献。**严禁编造不存在的论文标题或作者。**
* **一致性** : 摘要中的结论必须与正文实验章节的数据完全一致。

## 3. 结构规范 (Structure)

论文必须遵循一般大陆本科毕设的结构：

* **摘要 (Abstract)**
* **第1章 绪论** (背景、意义、现状、内容)
* **第2章 相关技术与理论** (RFM, K-Means, Dify/LLM, FastAPI)
* **第3章 系统需求分析与设计** (架构、数据库、功能模块)
* **第4章 关键模块实现** (ETL、聚类服务、Dify工作流对接、前端可视化)
* **第5章 数据分析与系统测试** (数据清洗结果、聚类K值选择、随机森林归因、AI策略评估)
* **第6章 总结与展望**
* **参考文献**
